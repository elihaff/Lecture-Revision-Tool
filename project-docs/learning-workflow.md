# Learning Workflow

Each lecture follows a fixed pipeline:

1. Upload slides
2. Generate notes and flashcards
3. Learn Mode (mandatory first exposure)
4. Structure Recall (mindmap step)
5. Flashcard Consolidation
6. Spaced Repetition Maintenance

Flashcards cannot be accessed until Learn Mode has been completed once.

Understanding score is derived from:

- card coverage
- review performance
- card maturity
